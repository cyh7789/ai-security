# playground

一個內建了洞的小應用，連載每一天要修的東西都在這裡面。

## 快速開始

```bash
npm install
export PROVIDER_API_KEY=sk-proj-8Kj2mNp4qR7sT9vXwYzA3bC5dE6fG1hI
node server/index.js
```

## 目錄

- `src/` 前端。`api.js` 直接拿著金鑰打模型 API
- `server/` 後端。訂單、工具、檔案、健康檢查各一支
- `test/setup.js` 測試設定
