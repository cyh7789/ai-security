# 27：給它一個編號，要它挑檔案

對應 Day 27（發表後補連結）。

Day 26 那一份是逐檔問「這個檔有什麼問題」，錯得很難看。這一份換一種問法：
給它一個 CWE 編號跟整份程式碼，要它回答**哪幾個檔要看**。這才是它練過的那件事。

環境跟 Day 26 同一套（Apple Silicon、`mlx-lm`、同一份 q4 權重），
取得方式見 [recipe 26](../26-what-low-looks-like/)。

## 跑

```bash
export ANTARES_MLX=./antares-1b-mlx          # 或你自己放的地方

python3 hunt.py "$ANTARES_MLX"               # 十三個類別各問一次，原始輸出存進 hunt/
python3 hunt.py "$ANTARES_MLX" --rename      # 對照組：檔名換掉再問一次
bash confirm.sh                              # 對它指出來的那個檔，真的打一次
bash verify.sh                               # 十一條檢查
bash mutations.sh                            # 突變測試，每一個都指名哪幾條該紅
```

離開碼照 Day 22 那份公約：0 全綠、1 有紅、2 環境不到位或有節被跳過，沒有結論。

第 10 條要重跑一整輪（約 73 秒）。`SKIP_RERUN=1 bash verify.sh` 可以跳過它，
但**跳過不是通過**：那一趟的離開碼是 2。

## 為什麼要問七個「這個專案沒有的類別」

因為只問埋過的那六類，量到的是「它找不找得到」，量不到「它會不會亂講」。
而 Day 26 從論文查到的那件事正好落在這裡：官方跑分的 Phase A 每一題都保證有洞，
Phase B（拿修補過的程式碼要它說沒問題）論文寫明沒有評測。

所以這一輪的十三個問題分成兩半：六個有答案的，七個答案是「沒有」的。
兩半的成績差很多，而差的方向就是那一格沒被量過的地方。結果見 `FINDINGS.md`。

## 這裡面有什麼

| 檔 | 是什麼 |
|---|---|
| `cwes.tsv` | 要問的十三個類別。描述逐字取自 cwe.mitre.org，「答案」欄是我判的 |
| `hunt.py` | 一個類別問一次，**原始輸出逐字存下來**，不判斷對錯 |
| `hunt/` | 我 2026-08-26 那一輪的存檔，十三份原始輸出加一份 `run.json` |
| `hunt-renamed/` | 對照組：七個檔名換成 `m1.js` 到 `m7.js` 的同一輪 |
| `confirm.sh` | 對模型指出來的那個檔真的打一次，有洞那份與 `execFile` 那份並排 |
| `verdict.tsv` | 我親手核的一輪。每一列附一句逐字出自存檔的依據 |
| `FINDINGS.md` | 這一輪的結論、判「這類不在」的理由、確認過的兩個真問題 |
| `verify.sh` | 十一條檢查，護的是「結論不准跟存檔分岔」 |
| `mutations.sh` | 突變測試。每一列指名**哪幾條**該紅 |

## 為什麼判準那一欄比模型的輸出重要

`cwes.tsv` 的「答案」欄是整份實驗的判準，尤其是那七個「無」。
每一條「無」我都要說得出理由，理由寫在 `FINDINGS.md`，一律是打開檔案數過。

沒有這一步的話，「七類裡亂指六類」只是我自己挑了七個容易讓它出錯的類別。

## 為什麼要有改名對照組

`hunt.py --rename` 把七個檔名換成 `m1.js` 到 `m7.js`。少了這一組，
「它挑對了」有另一個解釋：它只是認得 `tools.js` 這個名字。

實測跑過一次只給檔名清單（不給內容）問 CWE-78：真名那次它答 `server/tools.js`，
名字換掉那次它答了另一個檔。**只給檔名的話它就是在猜名字。**
要它讀內容，就得把內容給它。

對照組有一處不乾淨，`FINDINGS.md` 那節有寫：`src/render.js` 第一行的 import
把 `api.js` 這個真名帶進去了。

## 候選清單不是發現

模型交出來的那個檔，`confirm.sh` 打開之後看到的是**兩個**入口，不是一個。
模型只說「這個檔要看」，它沒說有幾處，也沒說打不打得進去。

那支腳本第一版的判準寫錯過一次，錯在拿文字當證據：payload 出現在錯誤訊息裡
被判成打進去了，而那其實代表它被當成參數安全地傳過去了。判準改成看檔案系統上
有沒有生出標記檔之後才分得開。這件事跟 Day 21 那條是同一句話：**守行為，不守形狀。**
