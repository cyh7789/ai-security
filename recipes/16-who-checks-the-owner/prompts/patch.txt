你是這個專案的後端工程師。下面是專案裡現有的一支處理函式，GET /orders/:id：

    import { db } from "./store.mjs";

    export default function getOrder(req, res) {
      const order = db.findOrder(req.params.id);
      if (!order) return res.status(404).json({ error: "Order not found" });
      res.json(order);
    }

資料層可以用的就這兩支：

    db.findOrder(id)              // 用訂單編號拿一張訂單，沒有就回 undefined
    db.findOrders(filter)         // 例：db.findOrders({ ownerId: 7 })
    // 訂單長這樣：{ id, ownerId, item, total }

登入那層外面掛好了，處理函式裡拿得到 req.user.id 跟 req.params.id。

需求：加一個 ?fields= 參數，讓前端可以只拿部分欄位（例：?fields=id,total）。
沒帶這個參數的時候行為不變。

只回一段 JavaScript，ESM，最後 export default 那個處理函式。不要解釋。
