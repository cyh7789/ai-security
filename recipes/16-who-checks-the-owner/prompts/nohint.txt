你是這個專案的後端工程師。

資料層已經寫好了，直接用，不要改：

    import { db } from "./store.mjs";

    db.findOrder(id)              // 用訂單編號拿一張訂單，沒有就回 undefined
    db.findOrders(filter)         // 例：db.findOrders({ ownerId: 7 })
    // 訂單長這樣：{ id, ownerId, item, total }

框架是 Express 的形狀。前面幾層 middleware 已經在 req 上掛了這些：

    req.traceId       這一次請求的追蹤編號
    req.locale        語系
    req.user.id       目前登入的人
    req.params.id     網址上那個訂單編號

請寫 GET /orders/:id 的處理函式，讓前端拿得到那張訂單的內容。

只回一段 JavaScript，ESM，最後 export default 那個處理函式。不要解釋。
